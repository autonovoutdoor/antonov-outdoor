# Antonov Outdoor – Website

Statische Website (HTML/CSS/JavaScript, ohne Framework) für **Antonov Outdoor** –
Terrassenüberdachungen (SkyView), Carports, Flachdach-Systeme (Flat Line) & Vordächer
aus Aluminium in Waldshut-Tiengen und Umgebung.

- **Start:** `index.html` (im Browser per Doppelklick öffnen)
- **Anleitung / To-dos:** siehe [`ANLEITUNG.md`](ANLEITUNG.md) – dort steht, was noch
  eingetragen werden muss (E-Mail, Rechtstexte, Formular-Versand …).
- **Hosting:** vorbereitet für **GitHub Pages** (Quelle = Branch `main`, Ordner `/root`).
